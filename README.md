## Publish free with GitHub Pages

1. With parent/guardian guidance, sign in to a GitHub account. Never share the account password in chat or with anyone offering to publish the site for you.
2. Create a **public** repository named `owen-abongo-omollo-portfolio` (or another clear name).
3. Upload the four files in this folder directly into the repository's top level. Make sure `index.html` is not buried inside another folder.
4. Open the repository's **Settings** tab, then choose **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then save.
7. Wait for GitHub Pages to finish publishing. The Pages screen will show the actual website address. For a project repository it normally follows this pattern: `https://YOUR-GITHUB-USERNAME.github.io/owen-abongo-omollo-portfolio/`.
8. Open the address in a browser and check the navigation, sections and email link on both a phone and a computer.

GitHub's official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Help Google discover the published site

1. After the site is live, open Google Search Console: https://search.google.com/search-console/ .
2. Add the exact live website address as a **URL-prefix property** and complete Google's ownership verification. For a GitHub Pages site, the HTML-file verification method can be used by downloading Google's verification file and uploading it to the repository's top level, then committing the change.
3. In Search Console, use **URL Inspection** to test the live homepage. If it is accessible and indexable, choose **Request indexing**.
4. Keep the page title and description clear, and add useful, original project updates as they are completed. Ask a teacher, school club or trusted organisation to link to the portfolio only if they agree.
5. Check Search Console later for indexing status and search performance. Google indexing is not instant or guaranteed.

Official Google guidance:
- https://developers.google.com/search/docs/monitor-debug/search-console-start
- https://support.google.com/webmasters/answer/9012289
- https://developers.google.com/search/docs/crawling-indexing/ask-google-to-recrawl

## Important distinction

GitHub Pages hosts the website. Chrome is a browser used to view it. Google Search visibility is a separate process that begins after the site is publicly available and Google crawls it.
